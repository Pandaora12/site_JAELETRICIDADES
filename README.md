# J.A Eletricidades — site

Site institucional da J.A Eletricidades (média e alta tensão, São Paulo e todo o Brasil).
Página única em HTML, CSS e JavaScript puro, sem build.

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Publicar no GitHub Pages

Settings → Pages → Branch `main`, pasta `/ (root)`.

## Arquivos

- `index.html` — a página
- `estilo.css` — identidade visual e layout
- `ja.js` — cenas sob medida (linha de torres, diagrama unifilar, energização, cubículos, chave arrastável, cursor-arco, régua de rolagem)
- `sites-incriveis.css` / `sites-incriveis.js` — motor de rolagem
- `logo-ja.svg`, `favicon.svg` — logo e ícone
- `docs/` — brief do projeto e prompts para gerar imagem e vídeo da chave fusível
